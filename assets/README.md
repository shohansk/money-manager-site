# Screenshots

Real app screens (sample data), 720px wide WebP, shown inside CSS phone frames on the home page: dashboard and goals (hero), transactions, budgets and investment detail (feature sections).

Full-size PNGs (1170x2532) for the Play listing live in `store/screenshots/` in the main repo. To regenerate, run the app with `bun run dev`, open it with `?demo=1` at a 390x844 phone viewport, and capture.
